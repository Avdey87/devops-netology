## Какие файлы игнорируются в terraform/.gitignore

Правила в файле `.gitignore` читаются построчно, где каждая строка — это шаблон (pattern), описывающий, какие файлы или каталоги Git должен игнорировать. Расшифровка использованных в `terraform/.gitignore` шаблонов:

- `**/.terraform/*` — будут игнорироваться все файлы, находящиеся внутри любого каталога с именем `.terraform`, расположенного на любом уровне вложенности. Символ `**` означает «любой уровень вложенности каталогов», а `/*` в конце — «всё содержимое этого каталога».

- `*.tfstate` — будут игнорироваться все файлы, имя которых заканчивается на `.tfstate`. Символ `*` соответствует любой последовательности символов (в том числе пустой).

- `*.tfstate.*` — будут игнорироваться все файлы, в имени которых есть `.tfstate.` — то есть имя начинается с любой последовательности символов, затем идёт `.tfstate.`, а после него — любое расширение (например, `prod.tfstate.backup`).

- `crash.log` — будет игнорироваться файл с именем ровно `crash.log` в любом каталоге.

- `crash.*.log` — будут игнорироваться все файлы, имя которых начинается на `crash.`, затем содержит любую последовательность символов, и заканчивается на `.log` (например, `crash.2024-01-01.log`).

- `*.tfvars` — будут игнорироваться все файлы, имя которых заканчивается на `.tfvars`.

- `*.tfvars.json` — будут игнорироваться все файлы, имя которых заканчивается на `.tfvars.json`.

- `override.tf` — будет игнорироваться файл с именем ровно `override.tf` в любом каталоге.

- `override.tf.json` — будет игнорироваться файл с именем ровно `override.tf.json` в любом каталоге.

- `*_override.tf` — будут игнорироваться все файлы, имя которых заканчивается на `_override.tf` (например, `prod_override.tf`).

- `*_override.tf.json` — будут игнорироваться все файлы, имя которых заканчивается на `_override.tf.json`.

- `.terraformrc` — будет игнорироваться файл с именем ровно `.terraformrc` в любом каталоге.

- `terraform.rc` — будет игнорироваться файл с именем ровно `terraform.rc` в любом каталоге.

Общая расшифровка символов, использованных в правилах `.gitignore`:

- `*` — соответствует любой последовательности символов, кроме `/` (в том числе пустой).
- `**` — соответствует любому количеству любых каталогов, то есть любой глубине вложенности.
- `/` в начале шаблона — привязывает правило к корню каталога, в котором лежит `.gitignore`.
- `/` в середине шаблона — задаёт путь относительно `.gitignore`.
- `/` в конце шаблона — означает, что правило применяется только к каталогам, а не к файлам.
- Строка, начинающаяся с `#` — комментарий, Git её не обрабатывает.
- Строка, начинающаяся с `!` — исключение из ранее заданного правила (re-include).
